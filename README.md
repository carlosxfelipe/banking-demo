# Banking Demo App

> 🚧 **Under construction:** The idea of this project is to experiment with some concepts.

This is a demonstration of a banking application built using React Native and Expo. 

It was built on top of my custom template: [Expo Starter Kit](https://github.com/carlosxfelipe/expo-starter-kit).

> [!NOTE]
> This is purely a demonstration app and does not process real transactions or handle real user data.

## Getting Started

Follow these steps to get the project up and running on your local machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/carlosxfelipe/banking-demo.git
   ```

2. Navigate into the project directory:
   ```bash
   cd banking-demo
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. Start the application:
   ```bash
   npm run start
   ```
   
   To run it directly on iOS or Android (requires simulator/emulator setup):
   ```bash
   npm run ios:go
   # or
   npm run android:go
   ```
   
   To run the web version:
   ```bash
   npm run web
   ```
